4. RELEASE MUST BE LATCHED
========================================================

Once all release conditions are satisfied, set something like:

release_ready = true

and preserve it until one of these happens:

1. RELEASE succeeds.
2. Deployment is explicitly cancelled.
3. A new deployment mission is started.

- current waypoint changed;
- PX4 stopped reporting a mission event;
- a telemetry update arrived;
- the operator waited;
- the UI refreshed.

========================================================
5. RELEASE CONDITIONS
========================================================

RELEASE becomes READY only when ALL required physical conditions are satisfied.

For the current deployment target:

- correct deployment mission is active/just completed;
- destination has been reached;
- UAV is physically landed;
- UAV is not in_air;
- altitude is at/below landing threshold;
- UAV is within configured target tolerance;
- no abort/RTL/return-home operation is active;
- node has not already been released.

Once these conditions become true:

release_ready = TRUE

and this state remains latched.

Do not require mission_state == "EXECUTING".

Do not require a specific exact current waypoint after landing.

Do not require the operator to click immediately.
